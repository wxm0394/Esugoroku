# Esugoroku：江户—明治时期絵双六玩法重设计

- 文档类型：玩法重设计提案（历史考据基线 + 可实现规则规格）
- 版本：Draft 0.1
- 适用项目：`wxm0394/Esugoroku`
- 设计目标：尽可能复原江户后期至明治时期纸面絵双六的玩法结构，而不是把它改造成战棋、卡牌 RPG 或资源经营游戏。
- 重要边界：本文区分“馆藏史料能确认的玩法”与“为了数字游戏而作的现代实现建议”。没有史料支持的内容不会伪装成历史规则。

---

## 0. 设计结论

Esugoroku 的核心循环应恢复为：

**看图读格 → 掷一枚六面骰 → 按棋盘本身的路线/出目指示移动 → 执行落格说明 → 轮到下一位 → 先到「上り」者获胜。**

主模式采用历史絵双六规则。玩家互动主要来自同一旅程中的先后、路线与落格事件，而不是攻击对手、偷资源、构筑护符或使用技能。

### 必须坚持的原则

1. **棋盘说明就是规则。** 不用通用战斗系统覆盖每卷棋盘的文字指示。
2. **骰子只决定移动。** AI 与人类走同一套规则，AI 不选骰面、不获得隐藏优势。
3. **棋子代表玩家。** 默认允许多个棋子停在同一格；相遇不自动击退、抢夺或封锁。
4. **格子要有叙事价值。** 每格是一处名所、一名人物、一段故事或一个时代风俗，不是单纯的数字跑道。
5. **保留絵双六的不同结构。** 廻り、飛び、飛び廻り应使用不同的移动数据模型。
6. **收集系统不干预胜负。** 浮世绘、人物画、图鉴与称号可保留，但作为鉴赏、解锁和收藏，不再提供移动 Buff。

## 1. 历史依据：哪些玩法可以确认

### 1.1 廻り双六（まわり双六）

从「振り出し」开始，按骰子点数沿棋盘的连续路线前进，目标是先到「上り」。东京学艺大学将江户时代的东海道道中双六视为廻り双六的基本形态：日本桥出发，按骰子点数经过东海道宿场，京都上り。

### 1.2 飛び双六（とび双六）

不是“沿直线移动后随机加减几格”。棋盘上的图格会给出骰面对应的目的地，玩家掷出相应点数后，直接移动到指定图格。部分骰面可能没有目的地；按东京学艺大学的说明，遇到未列出目的地的骰面时，棋子可以不动。

### 1.3 飛び廻り双六（とびまわり双六）

廻り双六与飛び双六的混合形式：一般路线按格前进，但某些格子会要求跳转、返回、休息或转入另一段路线。东京与学艺大学的资料将其明确列为廻り、飛び之外的复合形态。

### 1.4 落格指示与终点规则

可从江户时期的馆藏实例确认的常见指示包括：

- 「泊」「一回休み」：停一回合。
- 指定前进到另一格、退回某格或返回起点。
- 终点超出时按该棋盘印制的说明处理；有些棋盘要求折返，有些说明特定点数才可上り。
- 名所、宿场、名物、人物、诗歌、距离、渡河费用等信息本身也是棋盘内容。

这些不是所有絵双六都通用的强制规则。应逐卷定义，不能把某一张棋盘的规则误设成全局规则。

### 1.5 可参考的实际馆藏

- 江户后期《東海道五十三駅道中記細見雙六》：日本桥出发，沿渦卷经过宿场到京都；标注宿场距离、名物、渡河费用；川止め休息、箱根手形事件、四日市前进等。
- 《百種怪談妖物双六》：从儿童讲百物语场景出发，终点为妖猫，采用飛び双六形式。
- 《英勇揃伊呂波双六》：武将人物与いろは文字结合，格子本身的假名是辨认人物和后续移动的重要线索；主题是英勇人物与褒赏，不等同于玩家间战斗模拟。
- 明治《小學尋常科高等科修業壽語録》：46格描绘小学生活；明治《新版春遊子寳雙六》：31格描绘儿童游戏。
- 安政4年（1857）《しん工夫けん双六》：一个特别有价值的互动型例子。棋盘将江户名所环形排列，玩家分持狐、庄屋、猟師牌，分左右路线移动；相遇时玩狐拳，输家给出点心等。它是有史料依据的特殊变体，不应误认为所有絵双六都带有对战规则。

## 2. 全局基础规则（四卷共用）

### 2.1 玩家与器具

- 主模式支持 2–4 名玩家；可由真人与 AI 混合组成。
- 每位玩家使用一个独立棋子（駒）。
- 使用一枚 1–6 六面骰。保留项目现有公平骰子接口与骰子动画。
- 不使用第二枚战斗骰，不掷攻击/防御骰，不通过 AI 评估选取骰面。

### 2.2 开局

1. 选择一卷双六与玩家人数。
2. 每人选一个纯外观棋子（例如旅人、狐、武者、姫）；外观不提供属性。
3. 所有棋子放置在该卷的「振り出し」。
4. 决定先手，之后按固定顺序轮流行动。

### 2.3 回合流程

1. 当前玩家掷骰一次。
2. 按本卷的 `movementMode` 计算目的地。
3. 若骰面没有对应目的地，按棋盘规则停留原地，本回合结束。
4. 棋子移动到目的地。
5. 只执行实际停留图格上的指示；途经图格默认不触发。
6. 若落格指示要求休息、跳转、返回或额外路线选择，则按该格说明执行。
7. 若到达「上り」，结算胜利；否则切换下一位玩家。

### 2.4 多枚棋子同格

- 可以重叠停放多个玩家棋子。
- 不自动击退，不偷取物品，不禁止后来者进入。
- 不设置“同格即决斗”。
- 只有某张历史棋盘确实存在特定相遇玩法时，才在该棋盘作为可选特别规则启用。

### 2.5 终点

- 每卷单独声明 `goalRule`。
- 若该卷规定「ぴったり上り」，掷骰超出则按棋盘所示折返/停留；若原规则未要求精确点数，则不得擅自强加。
- 不设置通用资源门槛来锁住终点。

### 2.6 输赢

- 第一个抵达「上り」的玩家获胜。
- 不用收集数量、击退次数、声望值或护符数量决定胜负。
- 若未来加入多人限时赛，时间到时应明确标为现代比赛模式，不要伪装成历史通用规则。

## 3. 四卷重新设计

## 巻ノ壱：東海道五十三次道中双六

**定位：标准廻り双六（历史主轴）。**

### 结构

- 以实际东海道路线为骨架：日本桥「振り出し」→ 53宿场 → 京都「上り」。
- 推荐数据模型为 55 个关键停靠点（日本桥起点 + 53 宿场 + 京都终点）；若美术布局需要，起点/终点可作为独立大画格。
- 棋盘可采用历史常见的渦卷/环绕布局，但路线连线必须一眼可读。
- 各宿场格展示名称、浮世绘风景、宿场之间的距离或当地名物。

### 落格事件

以史料实例为模板，采用少量、直观的旅途指示：

- 川止め／渡河困难：一回休み。
- 茶屋／宿场：普通停留，不额外加 Buff。
- 箱根関所：若本格特别标注手形检查，则按该格文字退回指定宿场。
- 四日市等历史棋盘出现的捷径：前进到指定宿场。
- 终点超出：按本卷规则折返。

### 删除/转化

- 删除“名物三点收集才能获胜”及旅钱 Buff 逻辑。
- 名物和渡河费用保留在图格的说明文字中；若某一历史棋盘确有费用玩法，可做独立复刻变体，但不应把它扩展成通用货币经济系统。
- 删除同格追撞击退。

### 建议节奏

完整模式保留 53 宿场路线，目标是让玩家实际感到走过一段旅程。若要快速游玩，提供缩短路线的「道中略式」版，但不可把短版当作历史原版。

## 巻ノ弐：百種怪談妖物双六

**定位：飛び双六（按骰面直达目的地）。**

### 结构

- 振り出し：数名儿童围坐讲「百物語」的场景。
- 途中：河童、雪女、船幽霊、ろくろ首、九尾狐、百目鬼等怪谈场景。
- 上り：以馆藏同名双六的「古御所の妖猫」作为历史参照；可保留当前项目自己的终点命名，但应明确是艺术改编。
- 格子以图像群组/环形/散点方式排列，不使用一条从 0 到终点的线性链。

### 核心移动

每个图格拥有自己的骰面目的地表，例如：

```js
{
  id: "kappa",
  movementMode: "tobi",
  dieDestinations: {
    1: "yuki_onna",
    2: "funayurei",
    3: "rokuro_kubi",
    4: "nekomata",
    5: null,
    6: "start"
  }
}
```

- `null` 表示该骰面没有指定目的地，本回合不移动。
- 不使用 `+3/-2` 这种线性相对步数来伪装飛び双六。
- 可以有返回前一妖怪、返回振り出し、停留等特殊指示，但必须在图格上明确展示。
- 每个骰面图示应能被玩家看懂；可以提供六面路线预览，但不要用隐藏概率操作。

### 删除/转化

- 删除青行灯四枚“收集完后下次移动翻倍”的全局资源系统。
- 青行灯可变成图格中的插画、章节标记或解锁图鉴，不提供竞技 Buff。
- 删除“追撞击退”。

## 巻ノ参：英勇揃伊呂波双六

**定位：以武将人物与いろは假名组织路线的飛び廻り/人物双六。**

### 结构

- 以馆藏《英勇揃伊呂波双六》的主题为基线：人物格展示英勇、武将、传说人物；假名用于索引与识别。
- 由「出陣」开始，最终到「主君褒賞／上り」。
- 推荐扩展到完整的いろは人物序列，而不是现在的 24 格线性小跑道。
- 假名标记、人物名、人物简介和图像是此卷最重要的内容；不把每张人物卡变成装备槽。

### 移动方式

- 常规格按骰面前进。
- 特定人物格/分岐格使用印在格子上的假名标记指向下一格或下一段路线，体现「假名索引决定后续格」的传统趣味。
- 这是一种参考馆藏结构的数字化混合实现；史料能支持“假名同时用于人物索引与后续格指示”，但不能据此声称所有《英勇揃伊呂波双六》版本的完整掷骰规则完全一致。

### 落格事件

- 出陣、修行、功名、仕官、褒賞等叙事格。
- 少量「失策」「退却」「休息」格可按印刷棋盘风格指示退回/休息。
- 重点是人物识别和故事进程，不是双方互相打装备。

### 删除/转化

- 删除兜、太刀、陣太鼓三件装备的收集门槛。
- 删除同格一骑讨、推退三格、武具夺取。
- 删除猛攻/牵制/固守作为每次相遇的战斗姿态。
- 若要保留人物收藏，放在图鉴/人物解锁，不改变比赛规则。

## 巻ノ肆：源氏物語物語双六

**定位：文学物语型廻り双六，适当使用飞び廻り的剧情跳转。**

### 结构

- 从《源氏物语》章节和关键场景组织整条故事旅程。
- 建议以 54 帖/章的叙事结构为内容基础，做成连续或分段的长幅绘卷；章节图像与简短剧情是主要内容。
- 不把源氏故事强行改成善恶阵营竞赛。

### 移动方式

- 主线沿章节顺序推进。
- 少数章节可以有印在格子上的剧情跳转、休息或返回指示。
- 如需分岐，应对应明确的故事段落或场景，不使用掷骰奇偶决定善恶路线这种纯随机阵营选择。

### 删除/转化

- 删除善道/修罗道、善恶天平、怨念分数等与章节阅读无关的通用资源。
- 将和歌做为图格文本、鉴赏内容、图鉴收藏或章节完成记录，不做前进 Buff。
- 删除源氏卷的同格击退。

## 4. 可选历史特别规则：狐拳名所双六

这不是四卷共通规则，而是一个基于安政4年（1857）《しん工夫けん双六》的可选特别模式。

### 可复原的历史要素

- 名所沿圆形棋盘排列。
- 玩家持狐、庄屋、猟師三种角色牌。
- 玩家分成顺时针与逆时针两路移动。
- 相遇时按狐拳规则胜负；败者给出点心等。
- 个别名所格还会用狐拳主题写休息指示。

### 数字游戏的谨慎实现

- 应作为独立的「江戸の変わり種」模式或一张额外小棋盘。
- 不应将狐拳塞进全部四卷，也不应把它解释为普通絵双六的通用相遇规则。
- 可先实现成一局短小的双人特别游戏：角色循环克制（狐胜庄屋、庄屋胜猟師、猟師胜狐），相遇时进行一次选择；胜者继续原路线，败者交出一枚点心标记。不要造成永久性击退或装备掠夺。
- 上述循环规则是狐拳的数字化表达，具体胜负关系应在实现前对照馆藏说明与可靠资料再次核验。

## 5. 当前 V1.1–V1.3 系统的处理决定

| 现有系统 | 历史模式处理 | 可保留的位置 |
|---|---|---|
| 12种护符、每局选3种 | 从主规则移除 | 外观/图鉴/可关闭的旧版玩法模式 |
| 36张锦绘卡及开局Buff | 移除胜负加成 | 锦绘收藏、场景插画、解锁画册 |
| 辻风奇袭、主动重骰 | 移除 | 不保留在历史标准规则 |
| 同格追撞、击退、夺取武具 | 移除 | 仅狐拳特别模式可有轻量相遇玩法 |
| 东海道名物/旅钱 | 改为地点说明或历史棋盘特例 | 图鉴/旅程日志 |
| 百鬼青行灯收集与跳跃倍增 | 移除 | 场景灯笼、百物语章节记录 |
| 武者三备、装备门槛与战斗姿态 | 移除 | 武将人物图鉴与剧情进度展示 |
| 源氏善恶路线/天平 | 移除或按真实剧情重构 | 章节路线、和歌鉴赏 |
| AI Expectiminimax | 主模式不再需要通用战术搜索 | 仅对有骰面目的地选择/路线分岐的格子做有限评估 |
| 公平六面骰 | 保留 | 所有玩家共用同一掷骰入口 |
| Three.js 骰子、木版画、音效、离线运行 | 保留 | 表现层，不影响规则 |

建议在迁移期保留一个隐藏或明确标为「旧版扩展规则」的模式，以免老玩家的收藏数据失效；但新开局默认进入「历史絵双六」。

## 6. 建议的数据模型

目前 boards.js 主要用线性 `next`、`jumpDelta`、`jumpTable` 描述路线。建议升级为显式模式与显式指示，不要再把不同类型塞进同一种相对步数逻辑。

```js
const board = {
  id: "tokaido",
  movementMode: "mawari", // mawari | tobi | tobi-mawari
  startNodeId: "nihonbashi",
  goalNodeId: "kyoto",
  goalRule: { type: "exact-bounce" },
  nodes: [
    {
      id: "nihonbashi",
      title: "日本橋",
      illustration: "nihonbashi",
      next: ["shinagawa"],
      landingInstruction: null
    }
  ]
};
```

推荐图格字段：

- `id`, `title`, `reading`, `illustration`
- `caption`：图格叙事/历史说明
- `movementMode`：必要时覆盖棋盘默认模式
- `next`：廻り路线的后继节点
- `dieDestinations`：飛び双六的骰面→目的地表
- `landingInstruction`：`rest`, `moveTo`, `returnTo`, `restart`, `goalRule` 等结构化指示
- `sourceNote`：该规则来自馆藏实例，还是属于本项目的艺术改编

规则引擎必须：

1. 按棋盘模式选择移动算法。
2. 落格指示执行一次，防止连续跳转造成无限链。
3. 检查所有正式路线可从振り出し到达上り。
4. 对飛び双六检查无目的地骰面的停留语义。
5. 支持同格多个棋子。
6. 不让 DOM/动画层决定移动结果。

## 7. 单局长度与节奏目标

历史资料证明絵双六有 31 格、46 格、东海道 53 宿场等不同长度，但没有可靠证据可以据此推断当时一局平均耗时。因此，游戏时长是现代产品目标，不应包装成历史事实。

建议目标：

- 主东海道完整路线：约 14–20 次掷骰/玩家（这是按 53 宿场与六面骰作出的粗略体验估算，特殊格会改变实际值）。
- 怪谈飞び双六：约 12–18 次掷骰/玩家，通过未命中目的地的停留和长跳跃形成节奏变化。
- 武将与源氏长卷：约 14–20 次掷骰/玩家。
- 双人 AI 对局：目标 3–6 分钟；多人线下/本地对局可更长。

不要为了延长时间加入大量空白格。优先保证每格具有可读的画面、名字和说明；移动有变数但规则不繁琐。

## 8. 实施顺序与验收

### Phase A — 历史规则核心

- 新增 `movementMode` 和结构化落格指示。
- 实现 `mawari`、`tobi`、`tobi-mawari` 三种移动引擎。
- 删除主模式同格击退。
- 增加多棋子同格测试、终点超出测试、未匹配骰面停留测试。

### Phase B — 四卷地图重构

- 东海道：扩展到 53 宿场路线。
- 百鬼：改成真实目的地映射图，不再用线性 `jumpDelta`。
- 英勇：人物与いろは索引路线，不再有装备战斗门槛。
- 源氏：章节叙事路线，移除善恶计分。

### Phase C — UI/AI

- HUD 只显示当前玩家、位置、骰面、格子指示和路线预览。
- 不再显示竞技护符槽、Buff 经济、装备门槛等历史模式不需要的信息。
- AI 按同一流程掷骰与移动；仅当棋盘明确存在玩家选择时做选择。

### Phase D — 内容与回归

- 每个图格的日文标题、假名、简短说明和出处标注。
- 自动化检查每个图格的目的地有效、路线可达、上り可达。
- 进行 1000 局不同种子的模拟，记录平均掷骰数、停留次数、跳转次数、先手优势和胜率。
- 以真实浏览器完成 2人/3人/4人流程测试。

### 验收标准

- 主模式没有强制攻击、偷取、击退、Buff 或通用资源门槛。
- 三种移动模式的行为与定义完全一致。
- 每个特殊格的效果可由棋盘文字解释。
- AI 与真人的骰子入口、落格和胜负规则完全相同。
- 玩家能在不打开说明书的情况下看懂当前落格指示。
- 四卷在视觉上仍是浮世绘纸面双六，而不是现代战斗棋盘。
