## 1. Executive Summary
This report summarizes the engineering fixes applied during **Esugoroku V2.1.2 — Asset System Corrective Fixes**.
The primary objective was to resolve baseline issues identified in V2.1 / V2.1.1 where legacy image and sound fallback paths bypassed `AssetManager`, schema validation was incomplete, and WebAudio context states caused silent sound playback on user interaction.

All asset entries in `assets/manifest/asset-manifest.json` have been normalized to browser root paths (`/assets/...`), static file fallback handling in `server.js` was enhanced, `AssetManager` de-duplication and fallback logic was unified, Ajv schema validation was integrated, and automated testing tools were created.

---

## 2. Corrective Actions Completed

### 2.1 URL Path Unification (`/assets/...`)
- Transformed all 92 paths in `assets/manifest/asset-manifest.json` from relative paths (`assets/...`, `prints/...`, `fonts/...`) to absolute browser URLs (`/assets/...`).
- Enhanced `server.js` `safePath()` to route `/assets/*` requests to:
  1. `assets/` (root asset directory)
  2. `mobile/assets/` (legacy mobile asset directory)
  3. `public/assets/aistudio/` (AI Studio artwork sheet assets)
- Verified browser access via `curl -I` and automated HTTP endpoint check (`tools/test_assets_http.mjs`).

### 2.2 AssetManager Architecture & WebAudio Fixes
- Default `this.adapter` in `AssetManager` automatically instantiates `BrowserAssetAdapter` when running in browser environments (`typeof window !== 'undefined'`).
- Added `this.pendingLoads = new Map()` in `AssetManager` constructor to implement promise de-duplication during concurrent `preloadAsset(id)` requests.
- Updated `getUrl(id)` to return `null` (instead of silent Base64 placeholder) when an asset ID is unregistered, enabling callers to trigger procedural fallback logic.
- Updated `playSound(id, options)` in `AssetManager` to inspect `AudioContext.state` and execute `await ctx.resume()` prior to starting WebAudio buffer sources.

### 2.3 AssetRegistry Group Query Resolution
- Refactored `AssetRegistryImpl.getAssetsByGroup(groupNameOrPrefix)` to use a `Set` aggregating:
  1. `groupDef.assets` array from `manifest.groups`
  2. `asset.group` property matches across registered assets
  3. Prefix matches (`id.startsWith(prefix + '.')`) and exact matches (`id === prefix`).

### 2.4 Schema Validation with Ajv
- Installed `ajv` validator (`^8.20.0`).
- Refactored `assets/manifest/asset-schema.json` required properties so map keys act as asset IDs.
- Updated `tools/validate_assets.mjs` to execute true JSON Schema validation against `asset-schema.json`.

### 2.5 Master Sheets & Card Fallbacks
- Verified `preloadUkiyoeSheets()` in `mobile/js/nishikie_woodblock.js` resolves Master Sheet URLs via `AssetManager.getUrl(assetId)`.
- Verified `mobile/js/prints.js` retrieves ukiyo-e print URLs via `AssetManager.getUrl()`, with graceful procedural woodblock fallback when missing.
