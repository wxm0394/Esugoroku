# Esugoroku V2.1.4.2 — Bone Dice Runtime Integration Report

## Overview

This report documents the implementation of **Esugoroku V2.1.4.2**, focusing on bone dice runtime integration, Three.js factory extraction, and explicit error marking for unimplemented programmatic assets. The changes ensure that `model.dice.bone` creates genuine `THREE.Group` objects with face textures and 3D semi-embedded spherical pips, while all remaining 7 unimplemented programmatic assets throw explicit `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED` errors rather than returning fake mock objects.

## Programmatic Asset Status Audit

Out of the 8 programmatic assets defined in `assets/manifest/asset-manifest.json`:
- **1 Implemented**: `model.dice.bone` — Standalone Three.js bone dice factory (`createBoneDiceFactory`)
- **7 Unimplemented**:
  1. `piece.kokeshi` — 3D Kokeshi pawn (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  2. `audio.sfx.dice-roll` — Dice roll SFX (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  3. `audio.sfx.wood-clack` — Wood clack SFX (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  4. `audio.bgm.tokaido` — Tokaido BGM theme (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  5. `audio.bgm.yokai` — Yokai BGM theme (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  6. `audio.bgm.kesshu` — Kesshu BGM theme (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)
  7. `audio.bgm.genji` — Genji BGM theme (throws `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED`)

## Changes Summary

### Phase 1: Investigation

- **File**: `mobile/js/tabletop_3d.js`
- **Change**: Analyzed current `Tabletop3D.setupDiceBowlAndDie()` inline die & pip construction, identified 3D spherical pips, `BoxGeometry`, `MeshStandardMaterial`, `THREE.Group` composite structure, and face mapping `[2, 5, 1, 6, 3, 4]`.

### Phase 2: Factory Module Extraction

- **File**: `mobile/js/bone-dice-factory.js` *(Created)*
- **Change**: Extracted real Three.js bone dice creation logic into standalone ESM module exporting:
  - `createDieFaceTexture(faceValue)` — creates 256x256 canvas texture with Edo woodblock print palette:
    - Ivory bone surface: `#fffdf6` → `#f5ebd1` → `#d8c398`
    - Face 1 pip: vermilion `#ee4635`
    - Faces 2–6 pips: sumi ink `#3a2d24`
  - `createBoneDiceFactory(options)` — returns `{ group: THREE.Group, pickableMesh: THREE.Mesh }` with:
    - 6 textured faces using `BoxGeometry(1.68, 1.68, 1.68)` and `MeshStandardMaterial`
    - 3D semi-embedded spherical pips on all faces (1 large red pip for face 1, 5 black pips for faces 2–6)
    - Face order `[2, 5, 1, 6, 3, 4]` matching `BoxGeometry` face normal orientation
    - Optional shadow casting via `enableShadow` config
  - `FACE_ORDER = [2, 5, 1, 6, 3, 4]` constant for material face ordering metadata (`mat.userData = { faceValue: val }`)

### Phase 3: Tabletop3D Runtime Delegation

- **File**: `mobile/js/tabletop_3d.js`
- **Changes**:
  - Imported `createBoneDiceFactory` at top of file
  - Removed redundant inline `createDieFaceTexture` definition (now reuses module-exported version)
  - Replaced inline die & pip construction in `setupDiceBowlAndDie()` with delegation:
    ```javascript
    const { group: dieGroup, pickableMesh: cubeMesh } = createBoneDiceFactory({ enableShadow: !this.isSoftwareGl });
    this.pickableMeshes.push(cubeMesh);
    dieGroup.rotation.order = 'YXZ';
    dieGroup.position.set(this.bowlCenter.x, 0.42 + half, this.bowlCenter.z);
    dieGroup.quaternion.setFromEuler(getDieFaceUpEuler(1, 0.25));
    this.scene.add(dieGroup);
    this.dieMesh = dieGroup;
    ```

### Phase 4: Asset Registry Real Binding

- **File**: `assets/manifest/asset-registry.js`
- **Changes**:
  - Imported `createBoneDiceFactory` from `../../mobile/js/bone-dice-factory.js`
  - Updated `_createBoneDiceResolver` to invoke `createBoneDiceFactory(options)` and return real `THREE.Group` and `pickableMesh` under `factoryInfo.create()`:
    ```javascript
    _createBoneDiceResolver(registryEntry) {
      return {
        id: registryEntry.id,
        type: registryEntry.type,
        isProgrammatic: true,
        implementationKey: registryEntry.implementationKey,
        kind: "3d-dice",
        factoryInfo: {
          create: (options = {}) => {
            const { group, pickableMesh } = createBoneDiceFactory(options);
            return { kind: "bone-dice", faces: 6, isThreeJSGroup: true, group, pickableMesh };
          }
        }
      };
    }
    ```

## Key Technical Decisions

1. **Standalone Procedural Three.js Asset Factory** (`createBoneDiceFactory`):
   - Isolated ESM module for bone dice creation
   - Full backwards compatibility with `Tabletop3D` physics, pickability (`pickableMeshes`), animations, and particle anchors
   - Edo woodblock print palette: ivory bone `#d8c398`, vermilion face 1 `#ee4635`, sumi ink faces 2–6 `#3a2d24`

2. **Strict Separation of Implemented vs Unimplemented Programmatic Assets**:
   - Implemented assets (`model.dice.bone`) create genuine `THREE.Group` objects with face textures and 3D semi-embedded spherical pips via `createBoneDiceFactory()`
   - Unimplemented assets (`piece.kokeshi`, 2 SFX, 4 BGM themes) throw explicit `PROGRAMMATIC_ASSET_NOT_IMPLEMENTED` errors
   - No fake mock objects returned — callers must provide custom resolvers or WebAudio implementations

3. **Promise-based Concurrency De-duplication** (inherited from V2.1.4.1):
   - `AssetManager.pendingLoads` Map ensures concurrent `preloadAsset()` calls for the same programmatic asset share a single factory execution (execution count = 1)

4. **JSON Schema Draft-07 Conditional Validation**:
   - `if` asset type is `programmatic` → `implementationKey` is required
   - `else` (non-programmatic) → `path` is required
