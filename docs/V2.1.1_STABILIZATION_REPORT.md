# Esugoroku V2.1.1 Asset System Stabilization Report

## 1. 修复概况 (Fix Summary)

针对 Esugoroku V2.1 模块化资产管理系统进行的工程稳定化修复工作已全部完成：

1. **P0: Node.js 模块冲突修复**：将 `server.js` 完全转换为 ES Module (`import`/`export default`) 语法，与 `package.json` 中的 `"type": "module"` 声明保持完全一致。
2. **P1: 统一资产路径与服务器路由**：定义统一的 `/assets/` 浏览器网络请求路径规范，并升级 `server.js` 的 `safePath` 静态路由映射，使其能够无缝解析根目录 `assets/` 与 `mobile/assets/` 下的静态资源。
3. **P1: Master Sheets 资源迁移**：将 9 套 Edo E-Sugoroku 历史 Master Sheets 全部注册至 `asset-manifest.json` (`artwork.sheet.*`)，在 `mobile/js/nishikie_woodblock.js` 中建立 `SHEET_KEY_TO_ASSET_ID` 映射，并通过 `AssetManager.getUrl()` 实现预加载与资源解耦。
4. **P1: BrowserAssetAdapter 与 AssetManager 稳定集成**：修复了网络协议 URL (`http://`/`https://`) 解析逻辑，增强音频与图像资源的缓存管理，防止二次加载冲突。

- **URL 解析**: 由 `BrowserAssetAdapter` 统一调度，自动区分数据 URI (`data:`)、绝对网络 URL (`http://`/`https://`) 与相对路径 `/assets/*`。
- ** Master Sheets 绑定**: 在 `mobile/js/nishikie_woodblock.js` 中引入 `SHEET_KEY_TO_ASSET_ID`：

  - `yokai_kabuki` -> `artwork.sheet.yokai.kabuki`
  - `kesshu_tilted` -> `artwork.sheet.kesshu.tilted`

  - `genji_strips` -> `artwork.sheet.genji.strips`
