# Esugoroku：江户—明治时期絵双六玩法重设计

- 文档类型：玩法重设计正式规格书（历史考据基线 + 已实现规则规格）
- 版本：V2.0 (Historical E-Sugoroku Redesign)
- 适用项目：`wxm0394/Esugoroku`
- 设计目标：复原江户后期至明治时期纸面絵双六的玩法结构，而不是把它改造成战棋、卡牌 RPG 或资源经营游戏。
- 重要边界：本文与代码 (`sourceNote: 'museum-verified' | 'historical-adaptation'`) 严格区分“馆藏史料能确认的玩法”与“为了数字游戏而作的现代实现改编”。没有史料支持的内容不会伪装成历史规则。

---

## 0. 设计结论与实现状态

Esugoroku 的默认主模式（`ruleMode: 'historical'`）核心循环已恢复为：

**看图读格 → 掷一枚六面骰 (1–6) → 按棋盘本身的 `movementMode` 计算目的地 → 执行落格指示 (`landingInstruction`) 一次 → 轮到下一位 → 先到「上り」者获胜。**

主模式采用历史絵双六规则。玩家互动主要来自同一旅程中的先后、路线与落格事件，而不是攻击对手、偷资源、构筑护符或使用技能。同时保留：
- **特别历史变体模式 (`ruleMode: 'kitsune'`)**：复原安政4年（1857）歌川国郷《しん工夫けん双六》（狐拳名所双六），支持顺逆双向路线与相遇时的狐拳（狐・庄屋・猟師）点棒（菓子）互动。
- **旧版扩展规则模式 (`ruleMode: 'legacy'`)**：兼容保留 V1.1–V1.3 护符/手札/旅钱/青行灯/三备规则，所有 36 张锦绘与 12 种守札在主模式中作为浮世绘画帖图鉴与文化鉴赏系统保留。

### 必须坚持的原则

1. **棋盘说明就是规则。** 不用通用战斗系统覆盖每卷棋盘的文字指示。
2. **骰子只决定移动。** AI 与人类走同一套规则，AI 不选骰面、不获得隐藏优势。
3. **棋子代表玩家。** 默认允许多个棋子停在同一格（`allowSharedSquare: true`）；相遇不自动击退、抢夺或封锁。
4. **格子要有叙事价值。** 每格是一处名所、一名人物、一段故事或一个时代风俗，不是单纯的数字跑道。
5. **保留絵双六的不同结构。** 廻り (`mawari`)、飛び (`tobi`)、飛び廻り (`tobi-mawari`) 使用各自独立的移动数据模型与引擎。
6. **收集系统不干预胜负。** 浮世绘、人物画、图鉴与称号作为鉴赏、解锁和收藏，在历史主模式中不再提供移动或战斗 Buff。

## 1. 历史依据：哪些玩法可以确认

### 1.1 廻り双六（まわり双六 / `movementMode: 'mawari'`）

从「振り出し」开始，按骰子点数沿棋盘的连续路线前进，目标是先到「上り」。东京学艺大学将江户时代的东海道道中双六视为廻り双六的基本形态：日本桥出发，按骰子点数经过东海道宿场，京都上り。

### 1.2 飛び双六（とび双六 / `movementMode: 'tobi'`）

不是“沿直线移动后随机加减几格”。棋盘上的图格会给出骰面对应的目的地（`dieDestinations: { 1..6: targetNodeId | null }`），玩家掷出相应点数后，直接移动到指定图格。部分骰面可能没有目的地（`null`）；按东京学艺大学的说明，遇到未列出目的地的骰面时，棋子停留在原地（`tobi_stay`）。

### 1.3 飛び廻り双六（とびまわり双六 / `movementMode: 'tobi-mawari'`）

廻り双六与飛び双六的混合形式：一般路线按格前进，但某些格子会通过印在格子上的假名索引或故事说明要求跳转、返回、休息或转入另一段路线。

### 1.4 落格指示与终点规则 (`landingInstruction` & `goalRule`)

可从江户时期的馆藏实例确认的常见指示包括：

- 「泊」「一回休み」（`type: 'rest'`）：停一回合或多回合。
- 指定前进到另一格（`type: 'moveTo'`）、退回某格（`type: 'returnTo'`）或返回起点（`type: 'restart'`）。
- 终点超出时按该棋盘印制的说明处理（`goalRule: { type: 'exact-bounce' | 'reach' }`）。
- 名所、宿场、名物、人物、诗歌、距离、渡河费用等信息本身也是棋盘内容。

### 1.5 可参考的实际馆藏

1. **三重县综合博物馆藏《東海道五十三駅道中記細見雙六》**：日本桥出发，沿渦卷经过宿场到京都三条大桥、御所上り；标注宿场距离、名物、渡河费用；大井川川止め休息、箱根忘记手形退回小田原、四日市前进到关宿。
2. **东京学艺大学教育内容档案藏《百種怪談妖物双六》（E120200301）**：从儿童围坐讲「百物語」场景出发，终点为「古御所の妖猫」，采用飛び双六形式。
3. **国立国会图书馆藏《英勇揃伊呂波双六》**：武将人物与いろは假名文字结合，格子本身的假名是辨认人物和后续移动的重要线索；主题是英勇人物与主君褒赏。
4. **国文学研究资料馆藏《源氏物語五十四帖絵双六》 / 王朝文学双六**：从「桐壺」出发，巡礼源氏物语各帖和歌与人物，抵達六条院絵合上り。
5. **东京都立图书馆 / 国立国会图书馆藏《しん工夫けん双六》（安政4年/1857 歌川国郷 画）**：将江户名所环形排列，玩家分顺逆两路移动，相遇时以「狐・庄屋・猟師」狐拳决胜负并交出点心（菓子）。

## 2. 全局基础规则与实现架构

- **玩家人数**：支持 2–4 名玩家（`playerCount: 2..4`），配備四枚纯外观木驹（`旅人・壱`、`白狐・弐`、`武者・参`、`姫・肆`）。
- **公平六面骰**：所有玩家（真人与 AI）共用 `EsugorokuCore.rollDie`（32位 Mulberry32 + `UNBIASED_U32_LIMIT = 4294967292` 拒绝采样）。
- **单次落格指示执行 (`executeLandingInstructionOnce`)**：每次掷骰移动后，停留格的 `landingInstruction` 最多只执行一次，绝不产生递归无限链。
- **多棋子同格 (`allowSharedSquare: true`)**：所有四卷均允许多个棋子和平停留在同一格，无击退、无抢夺。
- **完本 53 宿场切换 (`setTokaidoRouteScale('compact' | 'full53')`)**：第一卷东海道支持在 25 格「道中略式」与 55 格「東海道五十三次完本（日本桥 + 53宿场 + 京都三条大桥）」之间实时切换。
