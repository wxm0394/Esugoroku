# 江戸—明治 浮世絵・絵双六 ─ E-Sugoroku (V2.0 Historical E-Sugoroku Redesign)

江戸後期〜明治期の紙面**絵双六（廻り双六・飛び双六・飛び廻り双六）**および安政4年（1857）歌川国郷『しん工夫けん双六』（狐拳名所双六）を、館蔵史料に基づいて復原・デジタル化したブラウザ用3D浮世絵双六ゲームです。

- **唯一規則正本 (Canonical Rules Authority)**: `mobile/js/core.js` ＋ `mobile/js/boards.js`
  - **既定モード (`ruleMode: 'historical'`)**: 伝統紙面絵双六（賽を振り、盤面の `movementMode` に従って駒を進め、止まった格の `landingInstruction` を1回実行し、先に「上り」へ着いた者が勝利。複数駒の同格共存・2〜4人対局対応）
  - **特別歴史変体 (`ruleMode: 'kitsune'`)**: 安政4年（1857）歌川国郷『しん工夫けん双六』（順回り・逆回り移動＋同格で出逢った際の「狐・庄屋・猟師」狐拳と菓子点棒の遣り取り）
  - **旧版拡張規則 (`ruleMode: 'legacy'`)**: V1.1〜V1.3 戦術双六モード（旅銭・四灯百鬼夜行・三備え合戦・護符・手札 Buff）も後方互換として選択可能
- **歴史絵双六再設計仕様書**: [`docs/EDO_MEIJI_ESUGOROKU_GAMEPLAY_REDESIGN.md`](docs/EDO_MEIJI_ESUGOROKU_GAMEPLAY_REDESIGN.md)
- **設計仕様書 (V1.1–V2.0)**: [`docs/GAME_DESIGN_SPEC_V1.1-V2.0.md`](docs/GAME_DESIGN_SPEC_V1.1-V2.0.md)
- **品質監査記録**: [`docs/V1.1-V1.3_ENGINEERING_AUDIT.md`](docs/V1.1-V1.3_ENGINEERING_AUDIT.md)
- **C11 エンジン (`core/esugoroku.c`)**: 初期 17〜19 格プロトタイプ（Legacy Prototype）として保持
- 実行環境: Node.js 18+ / モダンブラウザ（Three.js WebGL + Canvas 2D 浮世絵木版摺りシェーダー）
- 既定ポート: **3000**（または環境変数 `PORT`）

---

## 起動

```bash
node server.js
```

ブラウザで <http://localhost:3000/> を開きます。  
`server.js` は `mobile/` を配信し、全レスポンスに `Cache-Control: no-store, no-cache, must-revalidate` を付与します。

### 史料確認ルール (`museum-verified`) とデジタル翻案 (`historical-adaptation`) の区別

すべての盤面ノードは `sourceNote: 'museum-verified' | 'historical-adaptation'` を保持し、館蔵原図・大学アーカイブで直接確認できる仕組み（廻り・飛び・飛び廻りの分類、東海道の川止め・箱根手形・四日市飛び、百種怪談の百物語振出〜古御所の妖猫上りと無目的地停留、英勇揃のいろは仮名引き、安政4年『しん工夫けん双六』の狐拳・順逆移動・菓子点棒）と、画面構成上のデジタル翻案を明確に区別しています。

## 遊び方・モード切替

1. 上部バーの **`#select-rule-mode`** から規則モードを選択：
   - **歴史絵双六（江戸—明治正統） (`historical`)**: 既定モード。戦闘・武具奪取・護符Buffなしの純粋な紙面絵双六。
   - **特別盤：狐拳名所双六 (`kitsune`)**: 安政4年（1857）歌川国郷『しん工夫けん双六』。順回り／逆回りを切り替え、同じ格で行き逢えば「狐 ＞ 庄屋 ＞ 猟師 ＞ 狐」の狐拳で勝負し、負けた側が菓子（点棒）を1つ渡す。
   - **旧版拡張（戦術護符・V1.3） (`legacy`)**: 12種護符・36枚錦絵初期Buff・旅銭・青行灯・三構え合戦を有効化。
2. 上部バーの **`#select-player-count`** から参加人数（**2人・3人・4人**、木駒：旅人・白狐・武者・姫）を選択。
3. 巻ノ壱（東海道）では **`#btn-tokaido-scale`**（宿場規模ボタン）で **25格（道中略式）** と **55格（東海道五十三次完本：日本橋＋53宿場＋京都三条大橋）** を即座に切り替え可能。
4. **錦絵・守札・人物図鑑（全36枚＋12種＋24称号）** は、歴史絵双六モードにおいて勝敗に介入しない純粋な浮世絵鑑賞・蒐集アーカイブとしていつでも閲覧・拡大鑑賞できます。
